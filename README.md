<h1 align="center">Myra AI Assistant</h1>

<p align="center">
  An intelligent, voice-enabled personal AI assistant built for seamless interactions.
</p>

---

## ✨ Features

- 🤖 Gemini AI integration
- 🎤 Voice input
- 🔊 AI voice replies
- 💬 Smart chat interface
- 🌐 English & Bangla support
- ⚙️ Settings panel
- 📱 Android app support
- 🔐 Android permission support
- 🚀 Automatic APK build with GitHub Actions

## 🧠 AI

MYRA uses Google's Gemini AI for intelligent conversations and assistance.

## 🎤 Voice

MYRA supports microphone input and voice responses using available device/browser capabilities.

## 📱 Android

The project can be built as an Android APK using Capacitor and GitHub Actions.

## 🛠️ Technologies

- React
- Vite
- Capacitor
- JavaScript
- Gemini API
- GitHub Actions
